# 数据与隐私

应用不包含广告或统计 SDK。联网请求发给用户配置的服务器，包括登录、会话同步、模型与终端列表、附件、用量和任务操作。终端键盘的中文转换在本地完成。

手机会保存服务器地址、邮箱、加密登录令牌、按账号隔离的 SQLite 会话缓存、模型选择、终端恢复状态和最近一次用量统计。聊天数据与终端快照可能包含敏感文本；不要把应用私有数据目录当作可公开的诊断附件。

退出应用保留这些记录；退出登录删除当前账号的手机历史与令牌，服务器记录不受影响。登录过期保留离线历史。禁用系统备份，但设备 Root、系统或物理访问风险仍由设备环境决定。

发布仓库只包含经过检查的源码、固定离线词库和必要许可。源码包与 APK 不包含维护者的私人服务器地址、SSH 密钥、登录账号、测试令牌或真机消息。
