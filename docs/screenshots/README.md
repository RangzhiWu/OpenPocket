# 截图来源 / Screenshot provenance

四张图片来自 API 34 隔离 Android 模拟器中实际运行的应用界面。主应用使用 v0.3.0 的界面源码，与 v0.3.1 的界面一致；本地演示夹具提供虚构数据并切换页面，没有加入正式 APK，也不随公开源码分发。

These four images show the app running in an isolated API 34 Android emulator. They use the v0.3.0 UI, which is unchanged in v0.3.1. A local capture fixture supplies fictional data and switches pages; it is included in neither the release APK nor the public source.

| 文件 / File | 内容 / Content |
| --- | --- |
| chats.png | 会话列表和各自的保存状态 / Conversations and per-chat save status |
| conversation.png | 模型选择、消息及工具输出 / Model selection, messages, and tool output |
| terminal.png | 终端、底部键盘及拼音候选 / Terminal, docked keyboard, and pinyin candidates |
| usage.png | 演示统计、趋势与模型分布 / Sample usage, trends, and model breakdown |

所有会话、目录、命令输出及用量数字均为虚构内容。终端命令没有实际执行，用量不是实际消费或性能测量。顶栏明确标记“演示数据”。截图不含真实账号、凭据、私人服务器地址或用户消息。

All conversations, paths, command output, and usage figures are authored demo content. No terminal command is executed, and the usage figures are not real consumption or performance measurements. The header labels the content as demo data. No real credentials, private server addresses, or user messages are included.

截图经过人工检查，按原比例缩小到 540 像素宽，并重新编码为 PNG。没有修改应用内容或添加设备外框。应用界面目前以简体中文为主，因此各语言 README 共用这些截图。

Images are visually reviewed, proportionally resized to 540 pixels wide, and re-encoded as PNG. App content is not retouched and no device frame is added. The UI is primarily Simplified Chinese, so all README translations share these screenshots.
